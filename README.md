# Courier Money 2.12.0

Приложение для расчёта заработка курьера.

## Что нового в 2.12.0
- удаление одного конкретного заказа с подтверждением;
- обновлённые карточки заказов и кнопки;
- точный ручной километраж до 1 метра;
- можно вводить расстояние как `945 м` или `0.945 км`;
- в карточке заказа расстояние показывается в метрах и километрах;
- расчёт заработка использует введённое расстояние без округления до целого километра.

## Адреса и километраж
- адрес клиента вводится вручную;
- автоматический поиск/геокодирование адресов отключён;
- автоматический расчёт маршрута отключён;
- километраж для каждого клиента вводится вручную;
- в мультизаказе расстояния задаются отдельно: магазин → клиент 1 → клиент 2 → клиент 3 и т.д.

## Вес
- для каждого клиента можно указать вес в кг;
- тариф за 1 кг изменяется в настройках;
- оплата за вес рассчитывается как `кг × тариф за 1 кг`.

## Тарифы
- обычный заказ: 70 ₽ за забор + 105 ₽ за доставку;
- мультизаказ: за 2-й и последующие заказы оплата за забор не начисляется;
- километраж, вес и рейтинг учитываются по установленным в приложении правилам;
- все основные тарифы можно изменить в настройках.

## Сборка
Проект собирается через GitHub Actions. Для версии 2.12.0 ключ ORS не требуется: поиск и маршрутизация адресов отключены.
